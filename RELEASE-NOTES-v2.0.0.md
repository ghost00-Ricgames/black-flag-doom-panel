# Black Flag Doom Panel v2.0.0 — Foundry V14 Release

This version updates Black Flag Doom Panel for Foundry V14 and Tales of the Valiant / Black Flag 3.x.

## Highlights
- Encounter Doom uses total hostile CR and Monster Vault starting Doom rules.
- Optional Expanded Doom from the Game Master's Guide, disabled by default.
- Compact GM controls, explanatory hover text, once-per-encounter tracking.
- Independent Doom banks stored in Combat documents, and multiplayer player overlays that can select encounters.
- Independent controls for combat-start, gain, and spend audio, custom sound files, volume, and browser-local mute.
- Kobold Press Black Flag Reference Document attribution included in the package.

## Installation and updates
Install via Foundry Setup → Add-on Modules → Install Module using:

`https://raw.githubusercontent.com/ghost00-Ricgames/black-flag-doom-panel/main/module.json`

Existing installations using this same stable manifest URL can use Check Update.

The downloaded ZIP contains `module.json` at its root. A license notice and third-party attribution are included.

**Back up your world and finish active combats before upgrading from v1.0.2.** v2 stores encounter Doom on Combat documents instead of the former world setting.

This version is distributed directly via GitHub. It is not submitted to Foundry's official directory.
